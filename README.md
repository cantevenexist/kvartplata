# ЖЭУ: Система управления жилищно-эксплуатационным участком

Веб-приложение для автоматизации расчетов коммунальных платежей, управления задолженностями и учета жилого фонда. Система предоставляет разные уровни доступа для администраторов, бухгалтеров и собственников квартир.


## 🐳 Запуск проекта (Docker)

### ➡️ Шаг 1 – миграция:
Docker производит копирование (наследование) миграций баз данных моделей Django.
Для первого запуска воспользуйтесь следующей командой для создания инициализирумых миграций:
```
python3 djangoapp/manage.py makemigrations
```
Для работы команды требуется установленный Python и django.
Дальнейшие процессы выполняются в пределах Docker и не требуют дополнительных библиотек и программ

### 🗄️ Шаг 2 – сборка контейнеров Docker:
Для запуска воспльзуйтесь следующей командой:
```
docker-compose -f docker-compose.yml up --build
```
Для работы команды требуется установленный Docker.

## 🚀 Технологический стек

- **Backend:** Django, Django Allauth
- **База данных:** PostgreSQL
- **Контейнеризация:** Docker
- **Планировщик задач:** APScheduler (автоматическое начисление долгов 15 числа каждого месяца)
- **Frontend:** HTML, CSS, JavaScript

## 👥 Ролевая модель

В системе реализовано три роли с разграничением прав доступа:

| Роль | Доступные возможности |
|------|----------------------|
| **Администратор** | Полное управление пользователями, помещениями, тарифами, просмотр всей статистики |
| **Бухгалтер** | Управление начислениями, оплатами, задолженностями, тарифами и формирование отчетов |
| **Собственник** | Личный кабинет: просмотр начислений, история платежей, задолженности, данные квартиры |

## ⚙️ Ключевые функции

### 🔐 Аутентификация и регистрация
- Вход по имени пользователя / email и паролю (Django Allauth)
- Регистрация новых пользователей доступна только для `главный администратора`
- Валидация пароля (мин. 8 символов)

### 🧑‍💼 Панель администратора
- Управление пользователями (поиск, редактирование)
- Регистрация жилых помещений (привязка к владельцу по email/имени)
- Управление тарифами (создание, ставки, единицы измерения: `кВт·ч`, `м³`, `Гкал`, `м²`)
- Статистика: количество пользователей, помещений, активных тарифов

### 📊 Панель бухгалтера
- **Начисления:** создание начисления для конкретной квартиры (выбор тарифа, указание потребленного количества)
- **Оплаты:** просмотр всех совершенных платежей
- **Задолженности:** список должников с суммой и периодом, возможность оплаты
- **Тарифы:** просмотр и управление тарифами
- **Отчеты:** формирование и скачивание отчетов (Excel-подобное представление)

### 🏠 Личный кабинет собственника
- Просмотр информации о квартире (адрес, площадь)
- Текущий долг с учетом аванса
- Неоплаченные начисления с разбивкой по периодам и тарифам
- Оплата долга с возможностью внесения аванса (наличные, дата/время платежа)
- История всех платежей

### 🤖 Автоматические процессы (APScheduler)
Каждое **15 число месяца** планировщик APScheduler автоматически:
- Рассчитывает долги по всем активным помещениям
- Создает начисления на основе текущих тарифов и потребленных ресурсов (если данные переданы)
- Обновляет статусы задолженностей
